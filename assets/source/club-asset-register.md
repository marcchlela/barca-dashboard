# Club museum asset register

## Rebuilt museum (2026-10-07)

The current architecture is authored in Blender 4.5 by this project in `assets/source/club-museum.blend`, generated by `tools/blender/build_club_museum.py`. The 0.7 MB architectural export is `public/models/club/museum-room.glb`. Five matching local WebP fallback renders are in `public/images/club/museum/`. It is an interpretive stadium-to-museum setting, not an architectural survey or official digital twin. React controls the camera path; the environment contains no title data or trophy identity.
